# Сервер отчётов Lark

Принимает от Lark ошибки, падения, зависания и счётчики функций, хранит их в SQLite и присылает новые ошибки в Telegram.
Python 3.6+, только стандартная библиотека. Это копия сервера 2pic ([Egrom92/2pic](https://github.com/Egrom92/2pic), `server/`)
со своими именами, портом (8788) и базой.

- `lark_server.py` — сам сервер: `serve` (приём и уведомления), `report [--days 7]` (ошибки и использование в терминале),
  `selfcheck` (база пишется? Telegram отвечает? — присылает тестовое сообщение). Настройки — переменные окружения, см. начало файла:
  `LARK_TOKEN` (ключ, не короче 24 символов), `LARK_DB`, `LARK_LISTEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
- `test_server.py` — проверка от начала до конца: настоящий процесс сервера, подставной Telegram, настоящие HTTP-запросы.

```bash
python3 server/test_server.py
```

## Как развернуть

1. Положить `lark_server.py` на сервер, переменные — в файл, доступный только вам (`chmod 600`).
2. Запустить `python3 lark_server.py serve` под pm2 или systemd (он слушает только 127.0.0.1).
3. Снаружи — HTTPS-прокси на этот порт (nginx, Apache `RewriteRule ^(.*)$ http://127.0.0.1:8788/$1 [P,L]`).
4. Проверить: `curl https://<ваш адрес>/v1/health` → `{"ok": true, …}`, затем `python3 lark_server.py selfcheck`.
5. В Lark: зажать ⌥, шестерёнка → «Отчёты на свой сервер…» → включить, адрес `https://<ваш адрес>`, ключ = `LARK_TOKEN`
   → «Сохранить». Lark сразу отправит тестовое событие, в Telegram придёт «✅ Lark на связи».

## Что приходит

| Событие | Когда | В Telegram |
|---|---|---|
| `session` | каждый запуск: версии Lark и macOS, модель Mac, сколько устройств скрыто и заблокировано, сколько наборов | нет |
| `stats` | при запуске и раз в 6 часов: счётчики функций (`panel.open`, `device.choose.input`, `preset.hotkey`, `route.app.set`, `media.pause.tab`…) | нет |
| `error` | ошибка в журнале (`[error]`), с 30 строками журнала перед ней | 🔴 Ошибка в Lark |
| `error`, `crash` | прошлый запуск закончился не через «Выйти», со сводкой отчёта macOS о падении | 💥 Lark упал |
| `error`, `hang` | интерфейс не отвечал дольше 2 секунд | 🧊 Lark завис |
| `test` | кнопка «Сохранить» в окне отчётов | ✅ Lark на связи |

Названия треков, вкладок и наборов (в журнале они в «ёлочках») вырезаются до отправки. Одинаковые ошибки (разница только
в числах) приходят в Telegram не чаще раза в 30 минут, с числом повторов.
